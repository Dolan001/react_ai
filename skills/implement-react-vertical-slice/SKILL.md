# Implement React slice

Match semantic approved HTML and local patterns. Keep state near its owner and all API
access behind typed adapters with runtime validation. Cover loading, empty, error,
validation, authorization, keyboard, and responsive behavior. Run focused format,
lint, types, unit/component, build, and affected browser checks; stop for independent
verification.

Map the requirement IDs to familiar feature, route, component, and hook names before writing.
Prefer explicit PRD vocabulary; use a conventional capability name only when the PRD is silent.
Keep route files compositional and split components, hooks, schemas, API adapters, state, and tests
by responsibility before any source file exceeds 250 lines.

Read `references/production-delivery.md` for design fidelity, state ownership, API,
security, accessibility, performance, and browser verification rules.
