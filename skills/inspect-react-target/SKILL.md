# Inspect React target

Inspect manifests, config, route definitions, providers, state ownership, API adapters,
schemas, styling, tests, and approved design assets. Sample representative routes and
shared components rather than reading the entire tree. Record confidence, deviations,
and brownfield conventions that must be preserved.
